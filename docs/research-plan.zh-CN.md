# LPBF-CoupledFoam 开发与验证路线

本项目的目标是可扩展的激光—蒸发—气体—熔池—颗粒动态耦合框架，服务后续研究。更新时间：2026-10-09。已完成基线构建、连续相源码审计以及均匀合成相变的质量/温度/能量回归；已完成空间界面与激光的短时合成集成检查，完整连续相物理验证仍未完成，也未实现新的 CFD–DEM 耦合或加速算法。当前状态以 [项目状态](project-status.zh-CN.md) 为入口，测试证据见 [测试台账](test-register.zh-CN.md)。

## 固定基线与开发顺序

上游：https://github.com/laserbeamfoam/LaserbeamFoam ，标签 `V3.0`，提交 `f42e08a0bfc1749675beadcf7c6a90334d7aa9f8`。保留 GPL-3.0 许可证及上游历史。当前用户测试环境为 OpenCFD OpenFOAM v2512；v2506 保留为已做基础构建/运行检查的环境，不假定两版物性常数或所有数值结果一致。Foundation OpenFOAM 9/10 不是本项目已验证的替代环境。

| 阶段 | 交付 | 进入下一阶段的证据 |
|---|---|---|
| M0 基线（已完成当前检查） | 可重复编译、小算例运行、版本与环境记录 | 明确区分执行冒烟检查和物理验证 |
| M1-A 均匀相变基础审计（阶段收束） | 源项、热物性、子循环与能量参考审计；记录质量漂移限制 | 已有测试归档，不声称普适闭合；不继续孤立追踪小残差 |
| M1-B 连续相综合验证（下一开发包） | 空间界面输运、激光能量输入、熔化/蒸发及气体响应 | 同一综合矩阵验证空间行为、收支、分辨率与重启；达到文中阶段要求 |
| M2 解析颗粒 | 用户已固定解析路线：移动固体边界、几何排流、壁面力/力矩、内部导热及 DEM 接触 | 固定球/运动球、壁面分辨率、体积守恒、总动量/能量及共同重启 |
| M3 熔化及状态转换 | 固体颗粒到连续液相的守恒映射，VOF 液滴演化 | 质量、动量、焓不重复计入；串行/并行、重启一致性 |
| M4 文献对照 | 单一材料下的单道熔池、颗粒卷吸及飞溅统计 | 参数可追溯、网格/时间步收敛、与文献比较及误差解释 |
| M5 可选加速 | 固体热区分解、子循环等独立开关 | 与相同物理模型的全耦合参考模式比较精度、耗时和守恒 |

M1 必须先检查两套现有求解器源项，避免在反冲压力、蒸发动量源和气液界面应力中重复加入同一作用。不可压缩反冲压力模型不等于显式解析蒸汽羽流。当前可压缩主干作为工程起点；优先评估带蒸发源的低 Mach 变密度模式，并以同工况对照决定适用范围。新模式尚未实现。用户已明确颗粒采用解析求解，旧几何占据率 + 经验受力第一候选撤回。详见 [方程权衡与解析边界契约](resolved-gas-formulation.zh-CN.md)。LIGGGHTS/CFDEM 仍需兼容性审计。

建议独立定义 particleBackend 接口，保存粒子位置、速度、温度/焓、固相质量及接触状态；交换模块显式记录连续相和颗粒两侧的等量反向质量、动量、能量。是否采用外部 DEM 引擎应以当前 OpenFOAM v2512 接口、许可证、并行迁移、维护成本和接触物理需求作出决定。

## 阶段开发包与验收方式

采用“阶段开发包 → 用户综合运行 → 结果汇总 → 阶段判定”的方式。开发端不调用 WSL，不运行 CFD；仅做代码开发、静态检查和反馈分析。所有耗时仿真由用户执行。除非已有授权改变，保持这个分工。

当前 M1-A 收束依据：外层迭代 5/7/9 的结果未显著改善子循环 4 的质量与能量漂移。因此不再把增加迭代次数视为修复，也不继续追加同类微测试。保留五次外层迭代作为当前综合测试的起始配置，物理模型开关仍保持显式选择，不修改生产默认值。质量漂移根因登记为 Q01；只在综合验证中出现超出预设误差预算、结果不稳定或空间行为异常时，重新开启针对性排查。

M1-B 包含三类算例和统一反馈入口。M1B-01 第二版八组均通过既定短时门槛，阶段收束；保留此前启动、输运与零吸收失败。下一包 [M1B-02](m1b-portability.zh-CN.md) 使用同一个 40 步细网格激光相变算例，检查连续串行、分段重启及双进程的全历史一致性，补充分项温度方程诊断。首轮重启失配与第二轮字段读取/潜热回归保留；第三版 a7395edd 三轨迹与重启/MPI 比较通过，本包收束，门槛不变。避免再追加同类小残差试验。

M1B-02 已通过，进入 B2 的界面蒸发通量与气体响应模型开发，再向 B3 固定材料单道推进。若重启或并行失配，先解决存储/迁移/源更新问题；不能跳过失败直接进入颗粒。强蒸发、完整边界能量闭合和材料参数核对是后续里程碑，不由此轮微弱相变门槛替代。

| 算例族 | 要回答的问题 | 输出与阶段要求 |
|---|---|---|
| B1 空间界面输运 | 非均匀相分数下，输运、界面有界性和源项是否一致 | 相分数上下界/和、质量收支、界面位置；覆盖无相变对照与活动相变 |
| B2 激光—热—相变 | 吸收能量如何进入温升、熔化、蒸发和气体响应 | 激光输入、边界热/机械/质量通量、显热及相变项、温度和压力；按实际方程建立账本，不直接套用均匀基准门槛 |
| B3 固定材料单道 | 是否能形成可重复的熔池，并与公开基准建立对应 | 宽/深/长、热历史、网格/时间步敏感性；316L 参数及缺口先核对，再决定能否称为文献复现 |

每个算例族先有短时回归配置，再有较长验证配置，避免每次提交都跑全部昂贵案例。至少对关键案例提供两档空间/时间分辨率以观察敏感性；仅有两档不能宣称渐近收敛阶。选择代表案例检查串行/并行及重启一致性。阈值必须在运行前按具体模型、量纲、信号尺度和日志精度登记，不得看完结果再调到通过。

已结合书稿和论文更新 [D01–D08 模型决策](model-decisions.zh-CN.md)。M1C 按界面蒸发/气体响应与材料能量/移动激光两包交付，尚未实现；不新增均匀微测试。

具体批次、冻结范围及停止条件见 [M1 主要验收收束清单](m1-closeout.zh-CN.md)。CFD–DEM 设计讨论见 [通信与状态接口](cfdem-communication.zh-CN.md)，不等于已实现耦合。

M1-B 的阶段结束要求：三类算例均可重复执行；守恒/边界收支有相应诊断；关键输出的分辨率敏感性、已知限制和文献参数缺口成文。若变 Cv、移动界面下现有 rho*T 方程不足，应在该阶段统一改造能量闭合，而不是继续将等 Cv 的参考差候选推广成通用模型。M1-B 未完成前，不开展完整颗粒双向耦合或近似加速实现。

长期阶段编号继续沿用本文件 M0–M5。对话中的“颗粒耦合”和“可选加速”概括分别覆盖 M2/M3 与 M5，不另设冲突编号。阶段报告、测试台账、状态页与本计划在每次反馈/阶段开发包后同步更新；历史观察保留，失效解释明确标记。

## 单一材料与文献基准

首选材料 **316L**，主对照选 Zhang 等（2025），*Defects caused by powder spattering and entrainment in laser powder bed fusion process: High-fidelity modeling of gas, melt pool and powder dynamics*，Acta Materialia 288, 120816，DOI：[10.1016/j.actamat.2025.120816](https://doi.org/10.1016/j.actamat.2025.120816)。

选择理由是其物理范围直接对应本框架，而非仅因发表年代。它属于近期代表作；“经典”且更早的 Chen 与 Yan（2020）适合气固卷吸子模块，但不能单独验证完整熔池耦合。2025 年论文的[作者公开版本及补充材料](https://www.researchgate.net/publication/389060068_Defects_caused_by_powder_spattering_and_entrainment_in_laser_powder_bed_fusion_process_High-fidelity_modeling_of_gas_melt_pool_and_powder_dynamics)提供了较多模型和参数信息，仍不等于完整可执行复现包。

初始目标采用文中 316L 热飞溅工况：150 W，扫描速度 0.3 m/s，光斑直径 80 μm；运行前必须核对其光斑定义与我们的半径输入。补充表 S1 的 316L 参数如下，所有数值先作为待实现的文献参数集，不覆盖上游教程材料参数。

| 参数 | 数值（SI） |
|---|---:|
| 固相线 / 液相线 / 沸点 | 1659 / 1723 / 3086 K |
| 密度 | 7200 kg/m³ |
| 熔化 / 蒸发潜热 | 2.60e5 / 6.36e6 J/kg |
| 固 / 液比热 | 712 / 837 J/(kg K) |
| 固 / 液导热系数 | 19.2 / 22 W/(m K) |
| 动力黏度 | 0.006 Pa s |
| 发射率 | 0.4 |
| 参考表面张力 | 1.76 N/m |
| 表面张力温度导数 | −0.00043 N/(m K)，需匹配参考温度与公式 |
| 饱和蒸汽压参考值 | 1.013e5 Pa，不能视为各温度恒定压力 |

**复现缺口必须先登记，不能补猜后称为严格复现：**316L 的粒径分布与粉床坐标/随机种子、铺粉层厚及压实度；气体物性及边界条件；具体工况的吸收/光学参数；接触与阻尼系数；完整几何与网格分区；原始数值场和统计数据。其他材料试验中的粉层厚度、粒径范围不能直接移给 316L。书稿与期刊补充表确有数值差异，固液相线、比热和导热的对照已登记在模型决策表；主对照固定用所选期刊/作者版本参数，不混表。

建议分级比较：先无粉床单道熔池宽/深/长与热历史，再固定粉床，最后动态粉床与飞溅。后两级报告起飞数、粒径/速度/方向分布、卷吸区宽度和重复粉床的统计离散度；不同粉床下不以逐颗粒轨迹吻合作为验证标准。实验对照、跨求解器比较和代码验证须分别记录。

其他参考：

- Chen & Yan (2020), *Spattering and denudation in laser powder bed fusion process: Multiphase flow modelling*, [DOI](https://doi.org/10.1016/j.actamat.2020.06.033)：气固作用的模块级对照。
- Wang et al. (2022), *Mechanism of keyhole pore formation in metal additive manufacturing*, [DOI](https://doi.org/10.1038/s41524-022-00699-6)：可作为后续匙孔对照，材料是 Ti–6Al–4V，不能混入首个 316L 参数集。

## 可选加速的优先级

1. **先做基准性能剖析和非均匀网格。**测量压力、VOF、光线追踪、热方程、DEM 与通信的耗时；保留近场细网格。文献的外围粗网格不意味着外围关闭气体流动。
2. **远处固体仅解热是第一项近似加速候选。**仅在没有流动、相变界面或运动颗粒的远处固体内启用；外围保护气仍可能影响卷吸和羽流，不可按“远场”统一关闭。明确局部全物理区与全局热区的热通量/焓交换，加入温度、液相分数和热源距离唤醒条件及缓冲区。
3. **DEM 子循环和受控更新频率。**碰撞时间步与 CFD 分开；累计交换量保持守恒。降低接触刚度、冻结颗粒、减少光线更新不是无损优化，分别验证。
4. **后续候选：**光线缓存、远场液滴转拉格朗日粒子、移动局部细化。每项必须有关闭开关，并明确热源移动、界面形变或颗粒熔化时的失效和重新激活条件。

精度预算由使用目的设定，当前不预先宣称“误差小于某百分比”。每组比较固定物理模型、粉床、输出频率和硬件，记录峰值内存、总运行时间、时间步数量和各模块耗时；同时比较熔池几何、飞溅统计、温度历史、全局质量/能量误差。完整报告至少包含参考模式、单项开关、组合开关及分区/阈值敏感性。

热模型方法可提供分区思路，但不能将其加速比移用到本框架：[GO-MELT (2024)](https://doi.org/10.1016/j.cma.2024.116977)；[Substepped and advected subdomain methods (2026)](https://doi.org/10.1016/j.addma.2026.105098)。上述加速接口均为本项目拟开发内容。
