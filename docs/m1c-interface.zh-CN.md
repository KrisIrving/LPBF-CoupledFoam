# M1C-01 首版：界面质量通量与气体响应

状态：代码与集中验收入口已准备，用户侧编译/运行待验证。M1B-02 已收束，不重复其三轨迹。首版是 M1C-01 的界面质量/能量契约交付，不是完整羽流或低 Mach 模式。

## 实现范围

`alpha` 求解器控制新增 `interfacePhaseChangeModel`，默认 `legacy`，保持原算例源项路径。显式选 `prescribed` 或 `kinetic` 时，在任何相更新前用同一状态计算源；液/汽各取 −S_m/ρ_l、+S_m/ρ_v，体积源由两者相加，进入已有 vDot 压力耦合。原来的每对体积分布蒸发率不再同时执行。

面积密度首版取 |grad(alpha_l)|，S_m=j|grad(alpha_l)|。没有用有效界面厚度拟合面通量，也没有把混合单元温度称为真实表面温度。平面面积积分及其演化是独立验收项；复杂曲面、相邻多界面与网格方向敏感性尚未验证。解析颗粒几何不在本包。

`prescribed` 的 interfaceMassFlux 单位为 kg/(m² s)，允许正蒸发/负凝结；它是代码验证工具。`kinetic` 使用：

\[
j=C_a\sqrt{\frac{M}{2\pi RT}}(p_{sat}-p),\qquad
p_{sat}=P_0\exp\left[\frac{ML_v}{RT_b}(1-T_b/T)\right].
\]

当前仅支持纯液体/对应蒸汽，p 作为背压；保护气活跃时明确报错，不把总压当蒸汽分压。M 从 molWeight/1000 得到 kg/mol，R=8.314 J/(mol K)，沿用上游相变闭合的常数约定。测试 C_a=0.1 是合成输入，不是文献拟合。

源项库存限制器两侧共同限幅，限制本次显式相更新的最大占据变化，避免各相独立截断。日志同时记录请求量、实际量与限幅差；本包要求限幅基本不活动，不能通过大量截断掩盖源项错误。限制器不是强相变、高阶时间离散或输运有界性的通用证明。

能量项使用同一实际 S_m 乘固定相内能参考差，再通过现有 rCv 转为温度方程源。候选要求共同源、参考差和相等恒定 Cv；不将该受限模型推广到真实材料。没有添加额外 Knudsen 出口动量或另一次反冲：共享速度下内部转移携带的共同动量相消，出口相对速度/压力的跳跃闭合仍待实现。压力驱动气体响应不等于出口动量已经正确。

首版要求 nAlphaSubCycles=1；多子循环的界面源历史账本未实现，显式拒绝该组合。默认 legacy 分支已有多子循环行为保持原样。新候选的 MPI/重启仍须在新的代表工况复核，不能直接沿用弱相变旧包结论。

## 固定验收与账本

- 正常结束、时间序列完整、温度线性求解、相分数有界与和。缺少任一相的库存或边界通量，不算通过。
- 初始面积相对误差 ≤1e−6；全历史偏差 ≤5%。检查初始动力学/指定通量单位与符号，指定模式全历史验证 j×面积。
- 配对质量源误差 ≤名义速率×1e−12；能量源检查同一 S_m×参考差，预算同样为相对 1e−12。两者只是接口一致性，不能代替库存或能量守恒。
- 限幅绝对差 ≤请求/名义速率中的较大值×1e−4。总质量、液相和汽相均记录库存变化加边界累计通量，再与积分相变量核对。
- 三项质量收支的全历史残差预算固定为名义转移信号的 5% +1e−22 kg。信号取 j=1×预期面积×终点，约 1e−15 kg；不是用较大的总库存掩盖小转移误差。预算是代码验收初值，不是物理准确度承诺。
- 活动源必须产生正确方向的转移、速度响应 ≥1e−5 m/s；封闭域平均压力按蒸发/凝结方向改变 ≥1 Pa。开放案例需有汽相净出口量。

每个物理时间步只累计最后一次外层迭代的源及对应通量，不能把五次 PIMPLE 试算当成五次物理蒸发。边界累计使用右端点估计；网格/时间步对照给出差值，只用于敏感性观察，不能由两档宣称收敛阶。温度/组分造成的 EOS 库存变化不能单独冒充相变质量；因此汽相库存也必须核对完整账本。

## 接续与停止条件

本包反馈后，先按七组既定门槛判定界面源接口与收支；发现明确失败才追加必要诊断，不扩大均匀微测试。面积定位和库存收支未通过，不能仅增大激光功率进入羽流。

M1C-01 后续仍需出口动量/压力跳跃和能量定义、保护气组分/背压、代表活动工况的 MPI/重启；低 Mach 模式以共同界面接口为基础另行比较。M1C-02 接真实材料能量与移动激光；完整颗粒耦合在连续相主要验收后开展。运行通过不自动关闭 Q02 或完成整个 M1。
