# M2A revision17：静态控制体动量与角动量诊断包

## 本轮实现

从revision16受力差异继续，新增默认关闭的controlVolumeAudit；没有改完整壁面基、物理力或求解迭代。ControlVolumeAudit.H接入每个最终收束窗口、向DEM反馈之前。两个控制体按颗粒中心附近半宽R+6h/R+8h选取单元，实际边界是选中单元的网格面并集。强制不触及物理外边界，且源力/源力矩积分覆盖全部约束源。当前只支持固定/旋转静态单球和固定Euler步长；不是运动控制体或GCL实现。

使用最终U/p和该窗口冻结的advecting通量，与实际Gauss-linear对流、Gauss压力梯度、corrected Laplacian对应：净流入为黏性面通量−压力面力−对流动量通量，全部乘rho。库存率用rhoV(U−U.oldTime)/dt；源用最终实际约束源rhoV[lambda(rigid−U)+wallAcceleration]。首先逐单元重建显式残差，与保留的最终耦合矩阵残差比较，全局L1冲量缺口必须≤1e−12。此额外一致性门槛不替代旧全方程1e−11动量门槛。

内部面分别向owner和neighbour提供相反通量；处理器面只提供本地单元的面侧贡献，归约后共同内部面抵消。再将控制体面净通量与逐单元实际FV算子求和核对。不是把处理器面额外当物理外表面，也不是重新给DEM施加一次牵引。此构造的MPI数值一致性仍待原生验证。

## 角动量必须保留的余项

逐单元力矩使用单元中心相对颗粒中心的力臂，面通量力矩使用面中心力臂，两者差为逐面求和的(cellCentre−faceCentre)×flux。control-volume-history.csv独立保存arm_correction，验证：

库存角动量率−源力矩−面通量力矩−力臂修正 = 逐单元方程残差力矩。

原始面力矩差不要求为零，不能直接解释为物理颗粒力矩。当前方程的黏性面贡献是nu*snGrad(U)，这是向量Laplacian的通量；它不自动等于完整对称Cauchy应力牵引。对称应力、内部速度梯度、离散角动量余项的物理对应必须据本包证据继续审查。此包验证离散账，不能因为带修正的恒等式成立就宣称物理力矩正确。

原288点独立壁速与2/3/4h压力/黏性牵引诊断及其门槛全部保留。球内库存、反力账和解析载荷定义不变；新增控制体CSV保存两个控制体的库存、源、对流/压力/黏性分量、面净流入、面力矩、力臂修正及残差。暂未加入新的径向剖面或修改应力外推，避免把尚未定位的偏差拟合掉。

## 输出、重启与验收

每完整窗口写两行CSV，40窗共80行；共同重启在同一CSV追加，重启检查点核对controlVolumeAudit开关。没有新增需要序列化的积分历史状态，Euler库存直接使用OpenFOAM已恢复的旧时间场；其正确性由实际共同重启检查验证。

新增汇总检查时间与原机械历史逐窗一致、两层顺序和完整行数、有限性、源力/力矩覆盖、显式/矩阵匹配、面/单元匹配及带力臂修正的角动量恒等式。控制体不完整或失败时仍保留原算例与算子诊断，不写成通过。旧报告没有该开关，摘要行为保持原样。

门槛为矩阵/面匹配1e−12 N·s，角动量面匹配R×1e−12 N·m·s，源覆盖1e−12 N/1e−14 N·m；它们是新增离散恒等式检查，原5%滑移、10%最细受力/应力、2%相位及900秒/96/64预算不变。新增诊断可能增加少量工作量，没有宣称加速。

开发端73项M2A Python离线检查通过，包含非中心面力制造账本（省略力臂修正必须失败）、缺窗/重复层、源覆盖/矩阵缺口和生成器开关；3项Windows Git Bash模拟队列及脚本语法通过。独立执行joint汇总测试时发现新增模块依赖测试加载顺序，已改为按脚本自身目录加载；22项独立joint测试和全73项重新通过。旧trilinear、失败cubic与最新completeWallBasis三份原生报告摘要精确回归。新增C++头的编译、算子匹配、处理器面抵消和运行成本尚未验证；未执行开发端WSL/C++/CFD/DEM。离线制造账只验证验收逻辑，不冒充原生FV面通量测试。

一次原14组矩阵复用既有求解过程，归档包含新增CSV与汇总。由于未修改物理离散，上包受力失败可能继续出现；本包的目标是建立可定位的离散收支证据，不能期待新增诊断本身修复阻力或转矩。

收到反馈先核对编译和逐单元矩阵匹配，再核对两控制体/MPI/重启，最后比较账本、面收支和原表面牵引。若前两者闭合而牵引失败，集中审查对称应力/界面层/外推；若面收支或源覆盖失败，先修实际离散/并行账。M2A物理未关闭，不进入自由体/GCL/热，不扩大预算或降低原门槛。
