## 测试矩阵

全部是合成模型，活动相 Cv=800 J/(kg K)，初温 4101 K、零重力；不是 316L，也不涉及固态熔化或粉末。边界绝热，静态网格，五次外层迭代。只生成活动液/汽分布，其余七相为零。

| 族 | 两档网格单元数 | 初态与激励 | 要回答的问题 |
|---|---:|---|---|
| B1 advection | 80 / 160（20/40 × 2 × 2，第二版） | 两相相同密度 5000 kg/m³，x 向速度 1 m/s，液相条带 x=20–50 μm；相变关闭 | 界面输运的解析位移误差、相体积与有界性 |
| B1 spatial-evaporation | 216 / 1728（6³ / 12³） | y≥50 μm 液体、其余蒸汽；液体 rhoConst、蒸汽 perfectGas，p=80 kPa，激光关闭 | 非均匀相分数下活动相变与压力/温度更新是否可执行且有界 |
| B2 laser-heat | 216 / 1728 | 相同平面液/汽布局、p=100 kPa，1 W 静止激光，相变关闭 | 光线吸收与温度响应是否确实发生 |
| B2 laser-phase | 216 / 1728 | 同上，相变开启 | 激光加热、活动相变与气体响应能否联合执行 |

立方域边长 100 μm。界面输运使用 x 周期边界，其他速度边界 slip；压力在 top 平面固定参考值，避免该上游分支全部不可压缩时缺少参考约束。其解析均匀平移解在该平面法向通量为零。其余族为无滑移封闭壁面及 fixedFluxPressure。表面张力与温度导数均关闭，界面显式扩散关闭，以隔离本批检查；输运族同时关闭实际 thermophysicalProperties/interfaceCompression 表，不能仅以 fvSolution/cAlpha=0 代替。

短配置：输运时间步 1 μs、总时长 20 μs；其余族时间步 0.5 ns、总时长 10 ns；均为 20 步。子循环输运 1、其余 2；历史保护、源平均、共同源与内部能参考候选开启。输运两相参考差为零；其他族保留均匀基准的固定参考差。可选 verification 配置将总时长加倍至 40 步；它仍是合成综合检查，不能因命名而视为完成物理验证。

激光沿 +y，中心 (50,0,50) μm，laserRadius=25 μm，Radius_Flavour=2。实际使用 radialPolarHeatSource=true、nRadial=5、nAngular=30，共 150 个极坐标采样；N_sub_divisions=2 是保留的面采样参数，并非当前模式下的实际射线数。两档立方网格使用相同射线采样，粗细差异仍包括射线步进和界面光学离散，不宣称纯网格收敛。记录配置输入能量与实际吸收能量，不把 1 W 直接当作全部被吸收。

## 新增开关与诊断

fvSolution 保留启动 CorrectPhi 所需的 pcorr/pcorrFinal 配置（通过 pcorr.* 匹配，PCG 及 GAMG 预条件器，沿用上游 1e-5 容差）。生成时检查 alpha、pcorr、rho、p_rgh、T、U 及其相应 Final 名称均被求解器条目覆盖；缺项在网格与求解前报告，不等用户跑八组后才发现。此检查只验证配置覆盖，不能代替 OpenFOAM 的完整字典解析与运行。

`phaseChangeEnabled` 位于 alpha 求解控制中，默认 true，保持上游活动相变。关闭时同时将液/汽两个方向的现有蒸发和凝结率置零，用于输运/加热对照；不关闭固液相变，也不改变其他项。开启时原质量率归一化问题仍保留。

`condensedPhaseOptics` 位于 controlDict，默认 false，第二版仅在 laser-heat/laser-phase 开启。原 update.H 在 vapour/air 分支累加电阻率，导致纯金属区近零；当前 Drude 光学下无阻尼的纯金属正入射吸收为零。候选改用：

```
eta_condensed = sum_condensed(max(alpha_i,0)/sigma_i) / max(alpha_condensed,1e-12)
```

单金属且存在凝聚相时 eta=1/sigma，本案例 sigma=1e6。气体不参与该权重；纯气体为零。光学混合规则仅在此单金属基准准备验证，不视为多组分光学模型已验证。源码原模式仍可选择。M1_OPTICS 每时刻记录凝聚相加权电阻率，摘要保存末态值，以区分激光未发射、光学未吸收与温度未响应。Drude 正入射公式离线检查支持非零电阻率产生吸收，但不是 CFD 运行证据。

第一版输运网格 40/80 的末态误差分别为 0.14300078/0.10183205，阈值为 0.12；粗档失败原样保留。第二版采用 80/160，是对空间分辨率不足的响应，不放宽门槛，也不把旧粗档重新判定为通过。

`spatialDiagnostics` 默认 false。开启后，每个时刻记录全部九相的 alpha 最小/最大值、相体积、x 一阶矩，以及相分数和的上下界。输运族另记录相对于平移条带**精确单元平均值**的体积加权平均绝对误差，避免把中心采样误差当作数值输运误差。当前解析式限于均匀 Cartesian 网格且条带未跨周期边界；两种配置的条带均未跨界。

仍保留连续相、原生相能量及温度分项日志。空间能量变化、吸收能量与二者差值只作观察；压力、能量输运、熔化与边界项尚未形成完整空间账本，不使用均匀案例的能量门槛。尚未实现通用守恒能量方程。

## 运行前固定的门槛

这些是本批开发集成门槛，不是文献精度或生产模型验收标准。后续若修改，须在新测试前说明依据，不因已有结果而调到通过。

| 检查 | 本批要求 |
|---|---|
| 执行与时间序列 | 正常 End，无致命/非有限日志；初态及每步诊断齐全，达到配置终点 |
| T 线性求解 | 所有输出最终残差 ≤1e-8，保持现有容差 |
| 封闭质量 | 全历史相对残差 ≤1e-5；周期接口不计作外边界 |
| 相分数 | 各相范围 [-1e-6,1+1e-6]，相分数和偏差 ≤1e-6 |
| 解析输运 | 末态体积加权平均绝对误差 ≤0.12，液相体积相对变化 ≤1e-5 |
| 激光族 | 初态之后吸收能量 >0，温度最高值较初温增加 >1e-8 K |
| 相变对照 | 关闭时全域温度相变源绝对值 ≤1e-20 kg K/s；开启时至少一次 >1e-16 kg K/s |

质量门槛比均匀测试宽，是空间集成的初始筛查；不意味着允许生产模型采用该误差。两档分辨率只报告敏感性，不证明渐近收敛阶。关闭相变时仍可能有蒸汽 EOS 密度变化，故不把蒸汽库存变化单独当作质量源。

## 用户运行与反馈

在已加载 v2512 的终端执行：

```bash
cd ~/LPBF-CoupledFoam
git pull --ff-only
BUILD_JOBS=8 bash scripts/m1b-integrated-test.sh
```

默认先跑 short 配置；暂不需要额外长运行。若后续阶段需要，可使用 `M1B_PROFILE=verification`，不要把两种配置的时长混为一组结果。

一次构建、八组串行算例、一个 m1b-integrated 反馈包。单组失败时保留该组日志并继续收集其余组；总摘要包含每项门槛、定量结果和粗细对照，通过状态为八组共同结果。构建失败也打包日志。`m1b-summary.json` 写出后才判断总门槛，不丢失失败信息。反馈包会包含网格和最终场，留在用户反馈中，不上传公开仓库。

## 阶段边界和下一批

上游现有相变源是按相体积分数计算的体积源，尚未实现独立的界面面积局限律。本批 spatial-evaporation 是源项与空间耦合检查，不能称为验证了真实界面蒸发、蒸汽羽流或反冲压力模型。

本批尚未覆盖 B3 真实材料单道、熔化、热/机械边界能量闭合、移动激光、并行和重启一致性。下一批依据八组反馈统一补齐空间能量账本和所需方程改造；在核对文献参数后建立单道配置。任何失败优先判断是否阻碍 M1-B 验收，再决定针对性修复，不回到无限追加均匀微测试的节奏。
