# M2A-02B：真实球面位置的单侧延拓候选与集中验收

2026-10-10。已实现候选代码、14组用户测试入口和预设门槛；**原生编译、CFD/DEM运行及受力精度尚未验证**。原M2A-01固定球细化失败不被覆盖。默认仍为 `volumePenalty`；新包显式选择 `surfaceExtension`，只允许静止球心的 fixed/rotate，无接触、单相等温、恒密度、均匀立方网格。

## 审查后的实现选择

当前问题是部分覆盖单元整体强约束可能把速度边界放在错误位置。选择先检验真实球面位置的 ghost-cell 延拓候选，而非直接用面开口率改造压力通量。ghost-cell 的边界重构思路见 [Tseng & Ferziger (2003)](https://doi.org/10.1016/j.jcp.2003.07.024)。本实现为项目自有、有限惩罚的单侧延拓候选，**不是该论文完整算法移植，也不继承其精度结论**。

对球内单元中心 C，令 n=(C−X)/|C−X|、d=|C−X|−R、B=X+Rn、I=B+2Δxn。只有 |C−X|≤R 的单元施加 λ=1000/Δt；球外中心单元不因体积率χ>0而整体刚体约束。

距球面不超过√3Δx的球内单元使用目标

`Ug(C)=Ub(B)+[d/(2Δx)]·[J U(I)−Ub(B)]`，`Ub(B)=V+Ω×(B−X)`。

更深内部用刚体速度。J为单元中心场的三线性插值；I的所有插值节点均在球外，因为距I不超过√3Δx，而I距球面为2Δx。√3Δx内部带覆盖球面三线性插值可能涉及的所有内部节点。几何采用真实R，不拟合粒径或经验阻力；该线性延拓并不严格消除离散曲率/插值误差。

每个耦合窗口保持同一个旧时间场、旧对流通量和静止几何。每次目标外迭代完整求解动量预测与原PISO内循环，再由当前球外速度重建Ug；最大目标差≤1e−7 m/s才允许收束，最多32次。每个内循环仍为8至96次、动量方程冲量L1≤1e−11 kg·m/s。这是求解场相关目标的外固定点循环，不是重复推进同一窗口。没有证明此固定点对一般流动必然收敛；到预算未达目标则失败，不推进DEM。

## 压力与受力账本

压力仍为运动学压力；压力方程、瞬态通量校正及离散外边界通量账本沿用当前机械基线。**没有把几何开口率写入拉普拉斯项，也不声称得到守恒切割单元法**。λUg作为动量源，λU为同一方程隐式项。

保留独立4³子单元χ，供内部虚拟流体动量积分Pi=ΣρχUV使用；这不是新的精确体积离散。惩罚合力C=Σρλ(Ug−U)V，颗粒流体力仍为 `Fh=−C+(Pi_new−Pi_old)/Δt`。由离散总流体动量关系可得物理流体动量 `Pphys=ΣρUV−Pi` 的变化满足 `ΔPphys=Δt·(外边界通量−Fh)`（含方程残差），因此固定球外支承−Fh与原线动量审计一致。力矩保留同类内部虚拟流体修正，**不是完整流体角动量守恒证明**。

外迭代收束后，计算C必须使用最后一次已求解方程的Ug；重建的新Ug仅供收敛差核对，不能在未再求解时替换力源。球面应力诊断不再施加到CFD或DEM，避免重复载荷。共同检查点记录约束方案，拒绝把旧体积约束的检查点直接作为新方案重启。

## 独立球面检查与误差来源

用12点Gauss–Legendre余弦纬度×24点等间距方位，共288个真实球面点，检查 `J U(B)−Ub(B)` 的面积加权RMS。这里直接插值最终流场，**不是把用于延拓的Ub代回去得到恒零滑移**。新包CSV `slip_rms` 指该真实球面插值滑移；旧包仍指χ加权体积目标差。另存 `bulk_target_slip_rms`，避免混淆延拓目标差与真实壁面无滑移。

压力与速度分别从B+2Δxn、B+3Δxn、B+4Δxn三个球外点取值。压力外推至B的权重6,−8,3；速度径向导数用包含Ub(B)的三次插值导数权重−13/12,3,−8/3,3/4再除Δx。刚体球面的切向导数给出黏性牵引

`tν=ρν[∂rU+n(n·∂rU)−Ω×n]`，`tp=−ρp(B)n`。

逐点积分压力/黏性力和力矩，与原动量力做末10窗均值交叉比较。外推包含已知刚体壁速，故它是不同公式的诊断，**不是完全独立于边界条件的真值**。有限Δx的径向外推和笛卡尔插值仍有偏差。

开发端只把精确连续Stokes场代入径向公式时，36³/48³/64³的阻力重构误差约11.38%/6.92%/3.94%，转矩约13.44%/8.90%/5.52%；不含CFD误差或三线性插值。这说明仅诊断外推已有有限分辨率偏差，不宜给粗网格任意极紧的应力一致性门槛。不是用户仿真结果，也不据此声明空间收敛。

目前全局笛卡尔网格场通过MPI归约复制到各rank，检查每个格点恰有一个所有者，最多50万单元。便于核对跨分区插值，**不具备生产分布式扩展性**；64³双精度U/p复制约8MiB/rank，还包含索引/临时内存及每次外迭代通信。后续应替换为局部探针交换；本阶段不声称加速。

## 集中矩阵与运行前固定门槛

固定球和转动球各包含36³/48³/64³，球心(0,0,0)与各轴0.25Δx偏移，合计12个工况；再加36³固定球MPI2和串行20+20窗共同重启，共14组。均40窗、Δt=1e−4 s、DEM子步1e−5 s。旧两个网格保留，不以换网格掩盖旧失败。新包暂不做平动/自由球，因为延拓候选尚未通过静态前置验证；之前通过的运动基线仍是旧方案，不能转移给新方案。

保留原几何体积误差≤5%、球面滑移≤5%参考速度、散度≤1e−6/s、真实线动量冲量残差≤1e−10 kg·m/s、方程L1≤1e−11 kg·m/s、时钟≤1e−12 s、稀疏ID7/40窗、原力/力矩分解与MPI/重启差异门槛。每组Stokes误差≤35%仍为原有限参考门槛。另在运行前固定：

- 每种球心相位的36→48、48→64误差增量均≤0.02；原36→48门槛保留。
- 64³两个相位的主受力/转矩参考误差≤10%，应力合力/力矩与主账本之差的向量范数/参考载荷≤10%。
- 每个网格两种球心位置的末10窗平均载荷差/同一Stokes参考载荷≤0.02。
- 目标外迭代≤32、重建目标差≤1e−7 m/s；内/外次数必须为合法整数，累计次数与预算一致。报告逐窗计算耗时及总校正成本，成本不以换宽物理门槛改善。

以上门槛不代表论文级精度、渐近收敛或完整CFD–DEM验收；运行后不为制造通过而放宽。任一个案失败仍继续收集其他案例，缺失比较明确标为未评估。默认单次求解最多900秒，超时保留状态和日志；可通过 `SURFACE_CASE_TIMEOUT` 改资源时间预算，不改变物理门槛。串行重启两段各有该预算。

## 用户操作与接续

只构建机械求解器，不重装LIGGGHTS、不重跑旧通信包，不要求先重跑原八组。

```bash
cd ~/LPBF-CoupledFoam
git pull --ff-only
export OPENFOAM_BASHRC="$HOME/OpenFOAM/OpenFOAM-v2512/etc/bashrc"
source .build/demo-liggghts.env
bash scripts/m2a-surface-test.sh
```

返回最后打印的 `.runs/m2a-surface-*.tar.gz`。完整网格/场留在用户本机，反馈归档保存日志、配置、CSV、摘要和共同检查点，避免大体积上传。运行期间原生编译及所有新物理门槛均待证实。开发端只做离线公式、分析器和脚本检查，没有调用WSL。

先整体评估静态表面候选的精度、相位敏感性与成本，再决定保留/修改该方案或改用明确推导的切割单元离散。通过后才扩展到规定/自由运动、移动扫掠体积/GCL、全角动量、MPI共同重启及多球接触；热/熔化、蒸发与LPBF仍分阶段验收。
