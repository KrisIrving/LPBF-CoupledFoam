# M2A 文献与离散方法复审

审查日期：2026-10-11。代码基线c56435ec；最近用户测试4aa89072。本文是方法审查和后续开发契约，不是新增原生通过证据。没有调用开发端WSL、CFD或DEM。用户提供的未出版书稿只用于内部核对，不提交原文件、截图或大段摘录。

## 审查结论

书稿和论文对当前工作有直接指导，但当前jointSurface并非书稿解析CFD–DEM算法的等同复现。我们选用了表面浸入边界/虚拟域路径，因而还必须借助这类方法的压力—边界力联合离散理论。最近的失败包含不同问题：体积惩罚方案的受力细化问题，ghost延拓的壁速/压力兼容问题，首轮joint的成本和细网格动量预算问题，以及revision2新引入的首窗发散。不能将它们全部归结为CPU慢、OpenFOAM版本或同一个已确定根因。

revision3关闭重复完整动量预测，只是回归候选，尚未证明解决联合算子的全部问题。现有42项离线检查验证若干几何、账本、摘要和小型代数性质，不能替代实际OpenFOAM面通量联合算子的验收。下一步优先审查离散响应与完整方程的一致性，再交付原集中矩阵；不通过增加预算、放宽门槛或换经验受力让结果过关。

## 代码审查发现

### 1. 高优先级：完整动量预测与对角约束响应混用

resolvedParticleFoam.C的动量矩阵含时间、对流、黏性项，而节点力响应使用rAU=1/A对角。response内部计算δUH=rAU·δa，再经面通量Poisson投影得到δU/δphi，并将δa累加到原动量源。首轮通过外层H更新传播非对角项；revision2额外在每次校正前完整求解动量，改变了压力/累计力的迭代映射，但没有同时重建相应的完整约束响应。

最近14组零完整窗，其中11组显式残差失败、3组超时；首窗仍用零热启动种子，动量与压力不断放大。tests/test_m2a_predictor_split.py的SPD反例证明这种混合更新可以失稳，即使每次D/J约束均满足。这是结构风险和日志相符的证据，不是单因素原生因果证明；GAMG、工作场复用等仍未单独隔离。

revision3已关闭jointFullPredictor。它恢复历史迭代结构，但保留了其他未完整验证的修改，不能直接宣布问题已解决。完整A逆若重启开发，必须连同压力、节点力、边界条件、面通量响应重建一致块求解，不能只重新打开开关。

### 2. 高优先级：J行独立和小型GMRES通过不证明实际壁面Schur算子良态

JointSphere.H检查归一化JJ转置的Cholesky主元，证明的是插值行独立；它没有包含压力投影。WallGMRES.H的小型原生核验验证Krylov实现，不验证OpenFOAM实际apply响应的线性、压力规范、可解空间或条件数。右缩放inverseDiagonal也只包含J·rAU·S，忽略压力投影。

闭合曲面的部分法向载荷可能与压力梯度存在近冗余，必须检查实际投影后的响应，不能直接把JJ转置的好主元用于解释压力消元后的矩阵。这里提出的是待检验风险，不声称已检测到本项目的法向零模；不能未经测量添加正则项、削除模式或改变物理载荷。

### 3. 高优先级：同位网格面通量是独立审查对象

代码连续性检查的是div(phi)，节点J插值的是单元中心U。压力矩阵的面通量修正与中心grad(p)并非可以随意互换的算子。当前显式构造deltaPhi与deltaU是正确的审查方向，但还需证明它们及方程源变化来自同一个固定窗口离散响应。

不能仅用中心速度的连续散度替代实际phi验收，也不能只检查节点壁速。fvc::ddtCorr依赖旧时间场；当前冻结旧时间和对流窗口，不应凭直觉给增量添加第二个不一致的时间修正。增量外边界应是基态边界的齐次线性化，压力参考规范必须统一；工作场复用要核查边界updated状态、矩阵缓存及响应重复性。

### 4. 中优先级：受力定义有合理结构，但空间精度未闭合

当前机械求解器明确使用运动学压力p，表面应力诊断乘rho转为物理应力；这与生产LPBF的Pa压力不同，接入时必须保留单位边界。节点力是积分力N，扩散除rho·V得到加速度，并使用同一权重插值，已有力/力矩/功交换检查。

虚拟域颗粒受力使用−约束合力+内部虚拟流体动量变化率，力矩有对应库存修正；它不是书稿开口控制体压力/壁面剪切表达式的逐项复制。内部库存目前用q4占据率，真实应力用流体侧外推，是两套独立近似。即使整体反作用账本通过，也可能存在真实表面牵引偏差；首轮粗阻力约13.6%、转矩约26%的误差并未通过最细10%门槛。不得再叠加经验阻力或将诊断应力第二次反馈DEM。

### 5. 已核对但不能用来解释本次失败的因素

静止球J/几何在压力迭代中固定，符合书稿冻结几何的原则；当前没有移动GCL项，不是任意移动颗粒方法已实现。fixed/rotate对DEM施加的流体载荷被支持/规定运动替代，故这些工况验证流体受力与规定壁速，不能证明自由运动双向动力学。rho=1、nu=0.1、R=0.01、U=0.01对应Re=0.002，低Re参考有意义；从规则球算例失败不能推断v2512平台选择失败。

## 下一开发包的固定契约

继续v2512及LIGGGHTS，不迁移OF10。继续表面IB工程路线，不把书稿开口面积因子直接乘到当前虚拟域方程上。书稿用于规定几何、力学、热学与耦合顺序的目标；IB文献用于约束离散与求解的具体推导。

2. 对实际原生response审计重复性、齐次线性、明确压力规范、面散度、源/速度/压力/通量的完整残差，以及投影后壁面响应的可解性。用代表固定/转动状态验证，几何和旧时间保持固定；不以几何oracle替代原生算子。
3. 优先检验revision3恢复的H更新及对角响应组合。若一致性/稳定性不成立，转为同一压力—节点力块的预条件迭代；既有GAMG可作为预条件组件，rAU作为近似预条件而非任意替换完整物理响应。保持非对称求解审慎，不照搬交错网格文献的CG结论。
4. 将算子诊断与原14组物理矩阵合并为一次交付：固定/转动三网格两相位、MPI2、共同重启。禁止在算子尚明显失稳时让剩余预算持续耗在异常压力响应；需要提前失败时报告真实残差和明确原因，不能标为物理通过。
5. 稳定与最细受力/应力一致性通过后，再做运动球GCL、自由平动/转动和内部传热；激光、蒸发与熔池最后集成到同一连续相压力约束。书稿的不可压缩蒸汽注入不会修复当前无相变单球离散失稳。
