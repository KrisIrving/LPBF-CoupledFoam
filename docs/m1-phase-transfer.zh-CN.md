# M1.2 质量率、潜热与子循环测试

## 统一接口的推导

约定 mDot > 0 表示液体变为蒸汽，单位 kg/(m³ s)。固定相密度下：

```
S_liquid = -mDot/rho_liquid           [1/s]
S_vapour = +mDot/rho_vapour           [1/s]
volumeSource = mDot*(1/rho_vapour - 1/rho_liquid)
latentPower = -Lv*mDot               [W/m³]
```

质量加权源项和为零。蒸发膨胀、凝结收缩。这里的 latentPower 是采用共同显热参考、将相间能差单独列为潜热时的热源表示；若总能/相焓本身已经包含该能差，则不能再次叠加。质量携带的显热、动能和压力功也必须按所用能量变量处理。

V3.0 的原始相源可从 mDot=rho_vapour*S_vapour 推得上述配对，已通过八项独立代数检查。问题不在配对本身，而在蒸发系数除以 rho_liquid、实际转移量乘以 rho_vapour 的归一化解释。因此本轮不擅自改动交换率。

## 温度源为什么还不能直接替换

生产方程求解 rho*T，并以 rCv=Σ(alpha_i/Cv_i) 换算功率、压力功和动能项。它不是 1/Σ(alpha_i*Cv_i)。上游 mass_dot 已包含各相密度及 Cv 换算，单位 kg K/(m³ s)。

在独立检查的固定 Cv 条件下，记 r=rho_v/rho_l：

- 蒸发的两相 massgen 总和为 Lv*mDot*(1-r)/Cv_v。
- 凝结的总和为 Lv*mDot*(rho_l/rho_v-1)/Cv_l（mDot 为负）。

这不是可直接与 Lv*mDot 数值比较的功率。尤其凝结方向，不能只把 massgen 的符号当作“吸热/放热”结论：相质量变化也进入 rho*T 的左端。下一步需将该温度方程、密度变化、EOS 和参考能一起还原成能量账本，再决定替换方式。仅将 mass_dot 改为 rCv*Lv*mDot 并不足以证明守恒。

## 本轮的可选子循环修正

加入 alpha 求解控制项 averagePhaseChangeSources，默认 false，保留上游行为。true 时，PCR 和温度相变源与 rhoPhi 一样，按 dt_sub/dt_total 累积，再用于外层压力/温度求解。nAlphaSubCycles=1 不改变行为。

这解决三个外层量采用不同时间代表值的问题，尚不能保证整体离散守恒。速率限幅 0.5/dt 随子步变化、相分数迭代与 EOS 反馈仍需验证。当前不修改原始瞬时质量/热源公式。

## 温度求解器对照（下一轮）

这是定位线性求解问题的对照，尚不预判 PBiCGStab 能收敛或原问题就是求解器选择。若候选也未达容差，再检查矩阵系数、尺度及残差定义。程序保留每次 T 求解的初始/最终残差和迭代数到 temperature-summary.json。

上游组允许作为已知不收敛的参考，候选必须正常结束且每次 T 残差达到容差，才能通过此轮门槛。一般六组脚本也新增温度收敛门槛，不再将正常退出等同于温度收敛。该门槛只检查 T，不代表所有方程或物理收支均已收敛。

用户反馈确认本案例 PBiCGStab/DILU 的十次 T 求解均在一次迭代达到容差。下一轮沿用该配置，但不修改上游教程的默认求解器。

## 受控液—汽混合测试

运行 `BUILD_JOBS=8 bash scripts/m1-phase-test.sh`。仍为 125 单元、每组 10 步；12 组覆盖蒸发/凝结初始驱动、平均开/关和子循环 1/2/4。场均匀初始化，metal1 和 metal1vapour 各 0.5，其余相为零；九相热物性列表暂保留。T=4101 K 对应该对初始饱和压力 100000 Pa，初始压力分别为 80000 和 120000 Pa。取消激光和重力，所有速度边界无滑移，温度零梯度，压力 fixedFluxPressure，避免边界通量混入相变响应。

这是合成闭合测试：沿用上游 EOS 和很小的汽化潜热参数，不用于材料复现或真实能量验证。初始方向可能随压力/温度变化翻转，不预设每步都保持同一方向。M1_PHASE 记录各相 EOS 质量与 alpha 体积，摘要记录初末变化；质量变化包含压缩性响应，不能直接当作积分蒸发量。原始瞬时相变率不变，下一步将根据结果检查相分数、总质量、压力/EOS 和温度的相容性。

## 封闭质量漂移与耦合阶段定位

最新用户报告中，十二组温度均收敛，但零边界质量通量下总质量发生漂移：凝结相对变化约 2.67e-5，蒸发约 -9.24e-8。相分数变化方向正确，不代表完整质量闭合通过。现在为合成封闭案例增加相对质量残差 1e-9 的诊断门槛；该值用于回归检查，不是通用物理精度标准。此前 result.txt 的成功仅覆盖当时的运行和温度门槛。

下一轮运行 `BUILD_JOBS=8 bash scripts/m1-coupling-test.sh`。四组比较两个相变方向与 PIMPLE 外层迭代数 1/3；均使用 PBiCGStab、源项平均打开、alpha 子循环 1。couplingDiagnostics 默认关闭，测试中开启，在 afterAlpha、afterContinuity、afterTemperature、afterPressure 分别记录 rho 与 mixture.rho() 的积分质量、平均压力、体积源和温度源积分。不同阶段的密度可能本就尚未更新，必须结合最终状态解读，不能把任何瞬时差值直接当作最终守恒误差。

保持瞬时源项与原有压力/相分数公式不变，先定位漂移是否由密度重置、EOS 响应或耦合滞后产生。所有案例会先运行，再统一检查温度及封闭质量门槛；若质量仍不通过，脚本以非零状态退出并保存压缩包。这是有效的诊断反馈，无需自行修改参数或反复重跑。

## 三次外层耦合与时间步检查

用户报告确认：三次外层迭代的蒸发组在日志精度内质量不变，凝结组最大时间历史相对偏差约 1.59e-10，两者通过当前 1e-9 门槛。一次外层迭代仍失败，因此该次反馈整体非零状态符合设计。

阶段记录显示第一次 alpha 更新使 mixture.rho() 的质量改变；连续方程求解保持封闭质量，第一次压力修正又令 rho 取 EOS 混合密度，留下偏差；增加外层迭代使两者趋于一致。该结果支持耦合滞后解释，但不等同于完整能量闭合，也不能将三次迭代作为所有案例的固定充分条件。

下一轮：`BUILD_JOBS=8 bash scripts/m1-refinement-test.sh`。十二组保持三次外层迭代和源项平均开启，比较两个方向、alpha 子循环 1/2/4、时间步 1 ns/0.5 ns。总时长仍为 10 ns，分别十/二十步。质量门槛现检查每个日志时刻的累计质量残差最大值，避免最终误差相消。温度和相库存用于比较时间步/子循环敏感性，目前没有自动宣称解已时间收敛。

这一步完成后才继续决定蒸发归一化及能量表示的改动。现有参数仍为上游合成模型，不能据此认定 LPBF 蒸汽质量流率或潜热准确。

## 子循环旧时间保护候选

时间步对照报告显示：alpha 子循环 1 的两个方向通过质量门槛，但凝结子循环 2/4 的最大相对残差约 7.06e-8～9.32e-8，仍失败。温度全部收敛。凝结蒸汽库存变化也随子循环改变，尚不能认定子循环无关，因此暂缓能量验证。

当前只有第一相通过 subCycle 保护全局旧时间场。v2512 的 subCycleField 会保存/恢复 oldTime 及 old-oldTime，并以时间索引保护外层迭代开始时的旧值。新增 protectAllPhaseOldTimes，默认 false；true 时，对其余相施加同类保护。只在进入子循环时更新一次保护索引，退出子循环时间对象后恢复历史，不在每子步冻结旧值。它针对可能的历史污染，尚未运行确认根因。

运行 `BUILD_JOBS=8 bash scripts/m1-history-test.sh`：四组仅比较凝结、子循环 2/4、保护关/开；固定三次外层迭代、源平均开启及 1 ns 步长。原始质量率、潜热与压力公式不改。已知失败的未保护参考也参与总门槛，因此整体非零退出可能是预期的；查看摘要中的逐组结果并发送完整反馈包即可。

## 保护回归通过与参考能账本

十二组保护回归已全部通过运行、温度与封闭质量门槛，最大历史相对质量残差约 1.59e-10。凝结时间步减半后转移量变化约 0.02%，固定步长下子循环结果接近。这只覆盖均匀合成闭合测试，尚无空间收敛、长时或 LPBF 验证。

下一轮运行 `BUILD_JOBS=8 bash scripts/m1-energy-test.sh`：平衡、蒸发、凝结三组；均固定三次外层迭代、子循环 1、保护与平均开启。平衡组初始压力为 P0=100000 Pa，另两组不变。保持方程和所有物性，仅读取诊断。检查脚本会拒绝未对应当前公开合成参数的设置，避免无意混用物性。

将 Lv 解释为参考汽化焓差，在平衡初始状态一次性确定蒸汽比内能常数偏置 C：

```
C = Lv - (e_v_native - e_l_native) - p_ref*(1/rho_v - 1/rho_l)
E_reference = sum(E_native_phase) + C*M_vapour + E_kinetic
```

这样参考状态满足 h_v-h_l=Lv，随后所有案例沿用同一常数。它不是按各案例结果调整的数值补偿，不改变求解器状态、源项或物性。封闭绝热且零激光的测试中，记录 E_reference 初末及全过程变化，用来区分参考态问题与方程收支问题。EOS 与显能模型是否热力学一致、离开参考状态的潜热差是否正确，均仍待检查。因此 energy-summary.json 只提供观察，没有自动能量通过判据，也不将原生显能变化直接认定为物理损失。
