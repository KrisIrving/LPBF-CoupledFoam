# M1B-02：代表算例的重启、并行与分项账本

状态：首轮三轨迹完成，MPI 一致性通过，重启一致性失败；第二版出现字段读取导致的潜热回归；第三版读取修订待运行。原门槛保留。M1B-01 第二版八组短时检查通过；本包沿用其细网格激光相变合成体系，不增加新的材料假设或调整原集成门槛。

## 运行

在已经加载 OpenCFD OpenFOAM v2512 的终端执行：

```bash
cd ~/LPBF-CoupledFoam
git pull --ff-only
BUILD_JOBS=8 bash scripts/m1b-portability-test.sh
```

只编译一次，顺序执行三条轨迹，最后生成 `m1b-portability-*.tar.gz` 反馈包。失败继续收集其他轨迹；无需再次运行八组矩阵。固定双进程使用 simple 分区 `(2 1 1)`，不自动扩大进程数。尚未用本包测量加速比。

## 配置与比较范围

三条轨迹都采用 1728 单元、100 μm 立方域、初温 4101 K、初压 100 kPa、1 W 激光、Cv=800 J/(kg K)、原有共同源与内能参考候选及凝聚相光学候选。时间步 0.5 ns，终点 20 ns，共 40 步：连续串行；串行 20 步写出后从 latestTime 续算 20 步；双进程连续 40 步。

重启保留 `log.first` 和 `log.restart`，要求两段均正常结束且 checkpoint 时间衔接。派生日志仅删除第二段初始化时重复的全局诊断，保留各实际时间步和分项记录。比较每个时间点的总质量、各相体积、最高/最低温度、累计吸收和参考能量变化；不重构 MPI 场，不宣称逐单元场一致。

在首次运行前固定一致性门槛：

| 全历史最大差值 | 允许值 |
|---|---:|
| 总质量差/基线初态质量 | 1e−8 |
| 各相体积差/计算域体积 | 1e−8 |
| 最低或最高温度差 | 1e−4 K |
| 累计吸收差 | 1e−14 J + 1e−5 × 基线末态吸收 |
| 各自扣除初态后的参考能量变化差 | 1e−13 J + 1e−5 × 基线末态吸收 |

这些是合成算例运行方式的一致性预算，不是物理准确度或强相变验收标准。每条轨迹还必须独立通过原集成门槛、完成时间序列且配置一致；缺失诊断不视为通过。

## 分项能量诊断与后续

显式记录公共恒定 Cv 后，使用现有 M1_T_BUDGET 日志，把每个时间步最后一次温度求解的储能、输运、扩散、机械、激光、熔化、相变和残差按 Cv 转为 J。方程左侧符号保留，激光输入通常为负。外层迭代不得重复累计同一时间步。

该账本在温度方程后、物性与压力修正前取样。非均匀场的显式重构输运不一定等于隐式矩阵输运；参考相能量是另一个账本。不得把小残差或参考能量接近吸收解释为通用能量守恒。

激光相变仍极弱，当前空间蒸发率是上游体积分布形式；强蒸发、界面通量、气体羽流、真实熔池、材料验证仍未完成。本包通过后推进界面蒸发与气体响应模型，再进入固定材料单道；若重启/并行失配，优先修复相应实现。

## 第二版状态恢复候选

controlDict 的 checkpointContinuumState 默认关闭，合成包显式开启。非零时刻启动要求保存的 phi、rho、epsilon1；恢复 phi 后不执行初始零散度投影，rho 新增写出，epsilon1 不按温度重新覆盖。已有 dgdt 的读写保持原样。rAU 创建和后续压力/动态网格修正仍保留。仅针对本包固定网格 Euler 时间推进，不能声称动态网格、高阶时间格式或复杂热物性的重启已验证。

新候选要求新生成的 checkpoint；不要把旧包缺少 rho 的时间目录当作兼容重启输入。缺字段应明确退出。候选机制来自源码和日志对照，编译与修复效果待用户反馈。

## 第三版：修正字段读取构造

v2512 中，使用默认值/默认场的 GeometricField 构造只通过 READ_IF_PRESENT 读取。第二版在该构造设置 MUST_READ 导致警告并未读取保存值。本次先严格检查 phi/rho/epsilon1 的字段头，再用 READ_IF_PRESENT 加载；epsilon1 不再回落到构造默认零。日志新增 epsilonMin/epsilonMax；这个无实际熔化的合成包预期 checkpoint 区间为 [1,1]，不是对未来真实熔化案例的限制。原比较门槛不变，运行待验证。
