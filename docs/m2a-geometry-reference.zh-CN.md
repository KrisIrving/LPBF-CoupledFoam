# M2A-02A：真实球体几何参考

2026-10-10。该模块是下一表面约束/受力集中包的独立几何参考，已完成开发端离线验证。**没有替换 resolvedParticleFoam 的几何或力学离散，不能关闭原固定球细化失败。** 不需要 OpenFOAM、LIGGGHTS、NumPy 或新的用户端仿真。

## 算法与输出

`scripts/sphere_geometry.py` 使用真实球心与半径。先把坐标归一化至单位球，球与轴对齐长方体的最小/最大距离用于内外分类；切割单元体积通过横截面圆盘与矩形相交面积积分获得。

圆盘/矩形面积用四个带符号象限积分相减计算，原函数为 `(x√(r²−x²)+r² asin(x/r))/2`。体积沿 x 积分，先在圆盘触及横截面边/角的位置分段，再用自适应 Simpson；局部体积率容差默认1e−8，达到深度预算仍不收敛则显式报错。记录误差估计，**它不是严格误差界，也不是流体精度**。

输出包含体积率、六个固体面面积、流体面开口率及切割单元内真实球面的法向面积积分。后者由闭合固体控制体的面向量和得到，**不是曲面标量面积**。另外提供直线段/球面交点和真实外法向；稳定二次根用于减少端点附近的消去误差。平面接触等退化情形不具有非零体积。

这些数据不自动构成守恒切割单元法，也不自动构成速度约束、压力方程或受力积分。当前面开口率完全没有写入 CFD 矩阵。该 Python 实现用于后续 C++ 交叉核对，不拟作为每个耦合窗口的生产几何后端。

## 固定矩阵与门槛

参考球 R=0.01 m，区域[-0.06,0.06]³。36³/48³/64³，对应 dp/Δx=6/8/10.667；每个网格包含球心(0,0,0)和各轴均偏移0.25Δx两种位置，共六组。同时独立重算旧4³子单元采样，不调用 CFD 的映射函数。

门槛在运行前设定：全局球体积相对误差≤1e−6，闭合球面法向积分范数/真实球面积≤1e−10，相邻单元共享固体面面积差/Δx²≤1e−12。原机械力学门槛不变。

开发端 Windows Python 首次六组全部通过：最大体积相对误差1.84e−11，最大法向闭合指标4.69e−16，共享面差为0。球冠、八分之一球、轴置换、缩放平移、分割守恒、圆面积和线段交点等解析测试通过。六组总计算约0.9秒，**仅为本机几何参考耗时，不是 CFD 加速证据**。

| 网格/球心相位 | 旧4³体积误差 | 旧非零覆盖支撑体积比 | 实际相交单元支撑体积比 |
|---|---:|---:|---:|
| 36³ / 0 | 0.41764% | 1.41471 | 1.62692 |
| 36³ / 0.25 | 0.41764% | 1.60039 | 1.91870 |
| 48³ / 0 | 0.57536% | 1.52192 | 1.52192 |
| 48³ / 0.25 | 0.57536% | 1.50700 | 1.68978 |
| 64³ / 0 | 0.32182% | 1.39742 | 1.44778 |
| 64³ / 0.25 | 0.32182% | 1.35179 | 1.46981 |

同样的体积误差可以伴随明显不同的支撑体积。相交识别更准确会纳入旧采样漏掉的微小切割单元，未必缩小支撑区域。因此下一求解器不能仅用更精确χ替换旧χ、保留所有相交单元的强整体速度约束，并据此宣称修复实际边界。
