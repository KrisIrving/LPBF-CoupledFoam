# M2A：解析颗粒机械耦合集中包

2026-10-09。前置证据：通信包在 `026247c9a232da011132792b25429261f75ad19c` 下构建、串行和双进程通过。M2A 为下一开发包规格，不是已完成的 CFD–DEM 求解器或可运行测试入口。

## 交付边界

在已确定的 OpenCFD v2512 上，将已运行的嵌入 LIGGGHTS 后端接入实际流体网格与解析固体边界。首包采用单相、等温、恒密度牛顿流体作为机械模块代码验证环境，隔离蒸发/材料能量问题；生产 LPBF 方程仍须包含相变、热/组分变密度和运动固体约束，不能把此验证环境的无相变连续性直接当作最终气体闭合。

借用 CFDEM 的几何定位、虚拟域/IB 速度约束及解析受力思路，按本项目方程和压力单位重构。保留 particleBackend 的状态/窗口所有权；CFD 控制流体时间步，DEM 管刚体运动和接触。不会把当前 measured-velocity 人造反馈力当作流体拖曳，也不会叠加经验阻力。

## 必须先审查的算法契约

| 契约 | 本包必须解决的问题 |
|---|---|
| 几何 | 固体掩膜/覆盖体积分数、实际半径、跨单元及分区映射；固定与运动几何的体积一致性，不借人工放大粒径掩盖误差 |
| 边界 | 平动+转动刚体速度、约束与压力投影相容；报告边界滑移和离散连续性残差 |
| 压力 | 明确运动学压力与 Pa 压力转换；在同一离散方程中处理固体约束，不叠加破坏前一约束的独立投影 |
| 受力/力矩 | 采用经验证的应力积分或等价 IB 体积分；推导虚拟内部流体惯性、移动积分域及体力项处理；不能直接对 IB 体积力取负就宣称完整受力正确 |
| 反作用 | 将计算出的流体作用用于 DEM，并核对真实流体侧动量及边界通量；不再只记录虚拟反向冲量 |
| 时间 | 使用同一耦合窗口和整段 DEM 子步；外层流体迭代不重复不可逆推进 DEM；同步/滞后误差可核对 |
| 并行 | 连续 ID 的全局 gather 只为旧 demo 限制；新接口保存稳定 ID、所有者和几何作用，处理一颗粒覆盖多 rank；DEM 分区迁移与 CFD 覆盖映射分别检查 |
| 重启 | CFD 状态、DEM restart、耦合时钟和累计作用共同恢复，避免重复窗口或遗漏反作用 |

算法审查来源及限制见 [平台/CFDEM 计划](platform-and-cfdem-plan.zh-CN.md)、[解析方程讨论](resolved-gas-formulation.zh-CN.md) 和 [通信接口](cfdem-communication.zh-CN.md)。完整离散和验收数值必须在交付运行包前固定；此规格不声称已有普适 IBM 惯性修正公式。

## 一次集中包的代表矩阵

1. 固定球低 Reynolds 数来流：检查壁面约束、流场与阻力；选有可追溯参考的工况，采用分辨率对比，有限域边界影响与网格误差分开记录。
2. 规定平动/转动球：检查移动几何体积、排流、速度约束及力/力矩；不以球穿过单元边界而无明显报错为验收。
3. 自由运动球：使用 CFD 实际受力回传 DEM，核对流体+固体动量、外力/边界通量和窗口敏感性，检查虚拟域惯性处理。
4. 代表性双进程与共同重启：检查粒子/覆盖单元迁移、同一物理轨迹及累计收支；不要求所有矩阵重复所有模式。

优先将同一机械模块和必要诊断组成一个有明确退出条件的集中包。不得为“证明路径”持续添加相同通信微测试；当前通过的两粒子通信包保留作工程基线，后续仅在后端变化时回归。

## 与其他阶段的关系

本包不包含颗粒内部导热、激光吸收、蒸发组分或部分熔化。M2 的热模块后续用内部导热参考与热交换账本验证；M3 再处理固液表示及润湿。M1C 收支失败和通用材料能量仍独立收束，未通过不能由机械包通过抵消。完整 LPBF 联合验证须在这些前置模块成立后开展，M4 文献基准及 M5 加速仍按主计划执行。
